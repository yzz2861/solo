## 1. 产品概述

档案照片OCR校对系统是面向档案管理员的专业校对工具，针对老档案数字化过程中OCR识别准确率低的痛点，提供智能信息抽取、低置信度标记、人工校对、缺页检测和抽检生成等核心功能，大幅提升档案数字化的质量和效率。

- **目标用户**：档案管理员、数字化加工人员
- **核心价值**：将逐张人工审核转变为智能抽检+重点复核，效率提升50%以上

## 2. 核心功能

### 2.1 用户角色

| 角色 | 登录方式 | 核心权限 |
|------|----------|----------|
| 档案员 | 本地应用 | 数据导入、信息校对、抽检生成、目录导出 |

### 2.2 功能模块

1. **数据导入**：OCR文本批量导入、照片索引关联、数据预览
2. **信息抽取**：姓名/日期/编号/页码/材料类型自动识别、置信度评估
3. **校对工作台**：照片预览、字段编辑、原OCR对照、批量操作
4. **质量检测**：低置信字段标记、疑似缺页检测、同名人员提醒
5. **抽检管理**：智能抽检清单生成、按置信度优先级排序
6. **目录导出**：Excel/CSV导出、保留原OCR和修正记录

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|-----------|-------------|---------------------|
| 首页/导入页 | 数据导入模块 | 支持拖拽上传OCR文本和照片索引文件夹，支持CSV/JSON格式导入，显示导入进度和数据统计 |
| 校对工作台 | 列表视图 | 档案列表展示，支持按置信度、材料类型、页码筛选，低置信字段高亮标记 |
| 校对工作台 | 详情编辑 | 左侧照片预览（支持缩放、旋转），右侧字段编辑面板，显示原OCR值与修正值对比 |
| 质量检测 | 低置信概览 | 统计各字段低置信率，展示疑似缺页列表，同名人员冲突提醒 |
| 抽检管理 | 抽检生成 | 按低置信优先策略生成抽检清单，可配置抽检比例和优先级规则 |
| 抽检管理 | 抽检执行 | 抽检任务列表，标记抽检状态，支持批量通过/驳回 |
| 目录导出 | 导出配置 | 选择导出字段、格式（Excel/CSV），可包含原OCR、修正值、照片路径 |

## 3. 核心流程

档案员首先导入OCR文本数据和照片索引，系统自动进行信息抽取并计算各字段的置信度。随后在工作台中，档案员对低置信度字段进行重点校对，系统会标记疑似缺页和同名人员。校对完成后，可生成智能抽检清单优先复核高风险字段。最终导出包含原OCR、人工修正和照片路径的完整目录表。

```mermaid

    A["导入OCR文本和照片索引"] --> B["信息抽取与置信度评估"]
    B --> C["低置信字段标记/缺页检测"]
    C --> D["校对工作台人工修正"]
    D --> E["生成智能抽检清单"]
    E --> F["按优先级复核抽检项"]
    F --> G["导出完整目录表"]
```

## 4. 用户界面设计

### 4.1 设计风格

- **设计调性**：专业严谨的档案管理风格，兼具现代感和功能性
- **主色调**：深靛蓝 (#1a365d) 作为主色，代表专业和可信赖
- **辅助色**：琥珀橙 (#d97706) 标记低置信度警告，森林绿 (#166534) 表示已确认，玫红 (#be123c) 标记错误
- **字体**：标题使用 "Noto Serif SC" 宋体风格体现档案质感，正文使用 "Noto Sans SC" 确保可读性
- **布局**：三栏式工作台布局（左侧列表、中间预览、右侧属性），信息密度适中
- **交互**：悬停微动效，字段编辑即时保存，快捷键支持
- **视觉元素**：档案夹纹理背景、印章风格状态标记、手写编号字体模拟

### 4.2 页面设计概述

| 页面名称 | 模块名称 | UI元素 |
|-----------|-------------|-------------|
| 导入页 | 上传区域 | 虚线边框拖放区、档案图标动画、上传进度条、数据统计卡片 |
| 校对工作台 | 列表视图 | 数据表格、置信度色阶标签、筛选侧边栏、分页器 |
| 校对工作台 | 照片预览 | 图片查看器、缩放控制、旋转按钮、全屏切换 |
| 校对工作台 | 字段编辑 | 表单卡片、原OCR值灰显、置信度指示器、保存状态提示 |
| 质量检测 | 统计面板 | 环形置信度图表、缺页警告卡片、同名人员列表 |
| 抽检管理 | 抽检清单 | 优先级排序标签、进度条、批量操作栏 |
| 导出页 | 导出配置 | 多选字段组、格式切换、预览表格、下载按钮 |

### 4.3 响应式

- 桌面端优先设计，适配 1280px 及以上屏幕
- 中等屏幕 (1024-1280px) 自动调整侧边栏宽度
- 校对工作台核心区域支持 960px 最小宽度

### 4.4 特殊交互设计

- **置信度热力图**：在列表中用颜色深浅直观展示每条记录的整体置信度
- **印章式状态标记**：已校对、待复核、已通过等状态用圆形印章样式展示
- **逐字段比对**：编辑时并排显示原OCR值和修正值，差异处高亮
- **智能跳转**：点击低置信统计直接跳转到对应记录的对应字段
