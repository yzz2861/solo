## 1. 产品概述

医患短信随访摘要系统是一款面向医疗机构的智能化随访管理工具，通过智能解析患者短信反馈，自动分类整理症状变化、用药问题、不良反应等信息，帮助护士快速审核确认，为医生生成按严重程度排序的待处理清单，大幅提升医患随访效率。

- 核心价值：将零散、口语化的患者短信转化为结构化、可操作的医疗随访数据
- 目标用户：门诊护士（审核确认）、临床医生（处理决策）
- 解决痛点：医生逐条翻阅短信效率低、模糊信息难判断、紧急情况难以及时发现

## 2. 核心功能

### 2.1 用户角色

| 角色 | 登录方式 | 核心权限 |
|------|----------|----------|
| 护士 | 工号登录 | 导入短信、编辑人工备注、审核确认摘要、导出清单 |
| 医生 | 工号登录 | 查看待处理清单、按严重程度排序、标记处理状态 |

### 2.2 功能模块

1. **数据导入页**：批量导入短信记录、添加工号备注、查看导入历史
2. **智能分析页**：自动分类展示（症状变化/用药问题/不良反应/需回诊/只需观察）、原句依据高亮、同一患者时间线视图
3. **护士确认页**：逐条审核、修改分类、补充说明、标记家属代发、批量确认
4. **医生工作台**：按严重程度排序、不良反应优先展示、待处理/已处理标签、处理标记

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 数据导入页 | 短信导入模块 | 支持CSV/Excel批量导入、手动单条添加、导入进度显示、错误提示 |
| 数据导入页 | 人工备注模块 | 为每条短信添加护士备注、支持语音转文字输入、标注发送者身份（患者本人/家属） |
| 智能分析页 | 分类展示区 | 五大分类标签页展示：症状变化、用药问题、不良反应、需回诊、只需观察 |
| 智能分析页 | 原句依据区 | 每条摘要关联原始短信内容、关键词高亮显示、支持展开查看完整对话 |
| 智能分析页 | 患者时间线 | 同一患者多天反馈按时间轴展示、趋势变化标记、症状持续时间统计 |
| 护士确认页 | 审核编辑区 | 修改分类标签、调整严重程度、添加确认备注、标记模糊待查 |
| 护士确认页 | 批量操作区 | 全选/反选、批量确认、批量导出 |
| 医生工作台 | 待处理清单 | 卡片式列表、按严重程度降序排列、不良反应卡片置顶高亮 |
| 医生工作台 | 快速筛选 | 按分类/严重程度/时间范围筛选、搜索患者姓名（脱敏后） |
| 医生工作台 | 处理操作 | 标记已处理、添加处理意见、生成回诊建议 |

## 3. 核心流程

```mermaid

    A["导入短信数据<br/>(护士)"] --> B["智能分析分类<br/>(系统)"]
    B --> C["隐私信息脱敏<br/>(系统)"]
    C --> D["护士逐条审核确认<br/>(护士)"]
    D --> E["调整分类/补充说明<br/>(护士)"]
    E --> F["按严重程度排序<br/>(系统)"]
    F --> G["不良反应优先展示<br/>(系统)"]
    G --> H["医生查看待处理清单<br/>(医生)"]
    H --> I["标记处理/添加意见<br/>(医生)"]
    
    style A fill:#e3f2fd
    style B fill:#f3e5f5
    style C fill:#fce4ec
    style D fill:#e8f5e9
    style H fill:#fff3e0
```

**流程说明：**
1. 护士批量导入患者随访短信，可添加初步人工备注
2. 系统自动解析短信内容，识别口语缩写、家属代发标识
3. 系统对隐私信息（姓名、手机号、身份证号）进行脱敏处理
4. 智能分类为五大类，保留原句作为判断依据
5. 护士审核确认，可调整分类、补充说明、标记模糊信息
6. 系统按严重程度自动排序，疑似不良反应患者置顶优先处理
7. 医生查看待处理清单，标记处理状态并添加专业意见
8. 支持导出结构化报告供科室存档

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：医疗蓝（#1976D2）作为主色，代表专业与信任
- **辅助色**：
  - 紧急红（#E53935）：不良反应、高危患者
  - 提醒橙（#FB8C00）：需回诊、中等风险
  - 正常绿（#43A047）：只需观察、症状好转
  - 疑问灰（#757575）：模糊症状、待确认
- **按钮风格**：圆角8px，微投影，悬停有轻微放大动效
- **字体**：
  - 标题：Noto Serif SC（专业稳重）
  - 正文：Noto Sans SC（清晰易读）
- **布局风格**：卡片式布局，清晰的视觉层次，充足留白
- **图标风格**：线性医疗图标，简洁统一

### 4.2 页面设计概述

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 数据导入页 | 短信导入模块 | 拖拽上传区域、文件格式提示、进度条、成功/失败状态图标 |
| 智能分析页 | 分类展示区 | 标签页导航、分类统计数字、彩色标识圆点 |
| 智能分析页 | 原句依据区 | 引用样式卡片、关键词高亮背景色、展开/收起动画 |
| 智能分析页 | 患者时间线 | 垂直时间轴、节点连线、状态变化箭头标识 |
| 护士确认页 | 审核编辑区 | 左右分栏布局（左列表右详情）、下拉选择器、文本输入框 |
| 医生工作台 | 待处理清单 | 卡片瀑布流、严重程度色带、置顶醒目标识、快速操作按钮 |

### 4.3 响应式

- 采用桌面端优先设计，支持1280px及以上分辨率
- 护士端适配双屏显示，左侧列表右侧详情
- 医生端支持平板横屏查看，触控友好
- 关键操作按钮尺寸≥44x44px，确保触控精准

### 4.4 交互细节

- 卡片悬停时轻微上浮+阴影加深
- 分类标签切换有平滑过渡动画
- 严重程度排序有重排过渡动效
- 不良反应卡片有呼吸灯效果提示紧急性
- 隐私脱敏信息鼠标悬停可临时查看（需权限验证）
