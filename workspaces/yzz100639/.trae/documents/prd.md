## 1. 产品概述

新闻稿敏感表述提示工具，面向品牌公关与法务协同场景，帮助公关团队在新闻稿发布前快速识别绝对化表述、涉政敏感、数据口径缺来源、夸大措辞等风险语句，并给出温和改写建议。引用领导讲话、客户评价和历史荣誉做分类标注，不确定项留给人工确认。改稿后可重新扫描仅看剩余风险，人工确认保留的句子不再反复报错。

- 目标用户：品牌公关、企业法务
- 核心价值：降低新闻稿合规风险，减少法务逐句审核的沟通成本

## 2. 核心功能

### 2.1 用户角色

| 角色 | 使用方式 | 核心权限 |
|------|----------|----------|
| 公关编辑 | 直接使用 | 导入稿件、查看风险提示、应用改写建议、重新扫描 |
| 法务审核 | 直接使用 | 标记人工确认、查看修订导出 |

### 2.2 功能模块

1. **稿件导入页**：粘贴或上传新闻稿文本，一键启动扫描
2. **风险扫描结果页**：按句子展示风险标注、分类标签、改写建议，支持人工确认
3. **修订导出页**：导出修订建议（保留原句位置），支持重新扫描

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 稿件导入页 | 文本输入区 | 支持粘贴文本或拖拽上传 .txt/.docx 文件，显示字数统计 |
| 稿件导入页 | 扫描按钮 | 点击后启动敏感表述扫描，进入结果页 |
| 风险扫描结果页 | 稿件原文展示 | 左侧面板展示全文，风险句子高亮标注，带行号定位 |
| 风险扫描结果页 | 风险列表 | 右侧面板按风险类型分组列出所有问题，每项含原句、风险类型、改写建议 |
| 风险扫描结果页 | 人工确认 | 每条风险可标记"确认保留"，确认后不再报错 |
| 风险扫描结果页 | 引用分类标签 | 对领导讲话、客户评价、历史荣誉自动打标签，区分处理 |
| 修订导出页 | 修订建议表 | 列出原句位置、原句、风险类型、改写建议、确认状态，支持导出为 JSON/文本 |
| 修订导出页 | 重新扫描 | 公关改稿后点击重新扫描，仅显示剩余风险 |

## 3. 核心流程

用户打开工具 → 粘贴/上传新闻稿 → 点击扫描 → 系统逐句分析并标注风险 → 用户查看风险列表和改写建议 → 标记人工确认保留的句子 → 应用改写或手动修改 → 导出修订建议 → 修改稿件后重新扫描 → 仅查看剩余风险

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深灰底 (#1A1A2E) + 警示橙 (#FF6B35) + 安全绿 (#4ECDC4) + 中性白 (#F7F7F2)
- 按钮风格：圆角胶囊按钮，主操作用警示橙，确认操作用安全绿
- 字体：思源宋体（标题）+ Noto Sans SC（正文），编辑区等宽字体
- 布局：双栏编辑器风格，左侧原文，右侧风险面板
- 图标：线性图标风格，风险等级用颜色区分

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 稿件导入页 | 文本输入区 | 大面积编辑器，暗色背景，等宽字体，底部字数统计栏 |
| 稿件导入页 | 扫描按钮 | 居中大号胶囊按钮，橙色，带扫描动画 |
| 风险扫描结果页 | 原文面板 | 左侧 60% 宽度，行号+高亮标注，不同风险类型不同背景色 |
| 风险扫描结果页 | 风险面板 | 右侧 40% 宽度，风险卡片列表，可折叠，含分类标签 |
| 风险扫描结果页 | 引用标签 | 胶囊标签：领导讲话(紫)/客户评价(蓝)/历史荣誉(金) |
| 修订导出页 | 修订表格 | 全宽表格，交替行色，状态列用图标标识 |

### 4.3 响应式

- 桌面优先，双栏布局
- 平板端右侧面板可折叠为底部抽屉
- 移动端单栏，原文和风险面板切换展示

### 4.4 动效

- 扫描时原文区域有逐行扫描线动画
- 风险卡片从右侧滑入
- 人工确认后卡片淡出并移至"已确认"折叠区
- 重新扫描时对比差异用脉冲高亮
