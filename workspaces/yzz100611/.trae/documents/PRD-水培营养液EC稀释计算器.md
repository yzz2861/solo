## 1. 产品概述

水培营养液EC稀释计算器是一款面向水培种植户和农业技术员的实用工具，帮助用户精确计算营养液母液添加量，避免因浓度调配不当造成作物损伤。通过输入当前EC值、目标EC值、水箱体积等参数，自动计算需要添加的母液量或清水量，并支持多种单位换算和异常情况提醒。

- 核心价值：降低新手操作门槛，减少营养液调配更精准，记录历史数据便于农技员分析调整趋势。

## 2. 核心功能

### 2.1 用户角色

| 角色 | 使用方式 | 核心权限 |
|------|----------|----------|
| 种植户 | 直接使用 | 使用简化版界面，查看操作指导，记录每日数据 |
| 技术员 | 直接使用 | 查看完整计算过程，分析历史记录趋势 |

### 2.2 功能模块

1. **计算器主页**：EC稀释计算输入区、结果展示区、模式切换
2. **历史记录页**：历史EC记录列表、补液动作记录、趋势分析
3. **作物阶段选择**：不同作物阶段的EC参考值

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|-----------|-------------|---------------------|
| 计算器主页 | 参数输入区 | 当前EC、目标EC、水箱体积、母液EC、补水量、作物阶段输入 |
| 计算器主页 | 单位选择 | mS/cm与μS/cm切换，升与毫升切换 |
| 计算器主页 | 结果展示 | 显示需加母液量/清水量、异常提醒 |
| 计算器主页 | 模式切换 | 种植户版/技术员版切换 |
| 计算器主页 | 操作指导 | 种植户版显示分步操作说明 |
| 计算器主页 | 计算过程 | 技术员版显示详细计算公式和步骤 |
| 历史记录页 | 记录列表 | 按日期展示历史EC值和补液记录 |
| 历史记录页 | 趋势分析 | 展示EC变化趋势和调整趋势 |

## 3. 核心流程

用户打开应用 → 选择种植户/技术员模式 → 输入当前EC和目标EC → 输入水箱体积和母液EC → 选择作物阶段 → 点击计算 → 查看结果（种植户版显示操作步骤/技术员版显示计算过程） → 保存记录到历史

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：清新绿色系 (#22c55e / #16a34a），代表植物生长和农业主题
- **辅助色**：温暖橙色 (#f97316）用于提醒和强调
- **背景色**：浅绿渐变背景，营造自然清新的氛围
- **按钮风格**：圆润的圆角按钮，带有微妙的阴影和悬停效果
- **字体**：现代无衬线字体，清晰易读
- **布局风格**：卡片式布局，清晰的视觉层次
- **图标风格**：线性图标，与自然主题

### 4.2 页面设计概述

| 页面名称 | 模块名称 | UI元素 |
|-----------|-------------|-------------|
| 计算器主页 | 顶部导航 | 模式切换标签、历史记录入口 |
| 计算器主页 | 参数输入卡片 | 输入框带单位选择器、作物阶段选择器 |
| 计算器主页 | 结果卡片 | 大数字展示、状态颜色标识 |
| 计算器主页 | 操作指导区 | 步骤列表、图标引导 |
| 历史记录页 | 记录列表 | 时间线式布局、状态标签 |

### 4.3 响应式

- 桌面端：双列布局，输入区和结果区并排
- 移动端：单列布局，适配手机屏幕
- 触控优化：大按钮、充足的点击区域
