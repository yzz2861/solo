## 1. 产品概述

混凝土配合比现场换算系统，解决施工现场砂石含水率变化导致配合比失准的问题。输入实验室配合比、现场含水率、计划方量等参数，自动换算实际配料用量，支持打印现场配料单和技术复核表，实现批次追溯。

- 目标用户：施工员、技术负责人、试验室人员
- 核心价值：消除经验扣水误差，保证混凝土强度，实现配料全流程可追溯

## 2. 核心功能

### 2.1 用户角色

| 角色 | 说明 | 核心权限 |
|------|------|----------|
| 施工员 | 现场操作人员 | 录入参数、换算、打印配料单 |
| 技术负责人 | 技术管理人员 | 复核计算表、查看历史记录、批次追溯 |

### 2.2 功能模块

1. **配合比换算页**：实验室配合比录入、现场参数输入、实时换算结果、校验提示
2. **现场配料单**：施工员用简洁配料单（打印版）
3. **技术复核表**：技术负责人用详细计算过程表（打印版）
4. **历史记录查询**：按批次号/日期/试块编号追溯配料参数

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 配合比换算页 | 基础信息录入 | 批次号（自动生成+可编辑）、操作人、试块编号、浇筑部位 |
| 配合比换算页 | 实验室配合比 | 目标强度、每立方米水泥/砂/石/水/外加剂用量（支持kg、t、m³单位） |
| 配合比换算页 | 现场参数 | 计划方量、砂含水率、石含水率、外加剂比例、水胶比 |
| 配合比换算页 | 实时校验 | 含水率超范围（砂0-15%、石0-5%）、水胶比异常（<0.2或>0.8）、方量为零提示 |
| 配合比换算页 | 换算结果 | 修正后各材料用量（扣水后砂石用量、实际加水量） |
| 配合比换算页 | 打印输出 | 打印现场配料单、打印技术复核表、保存记录 |
| 历史记录页 | 查询列表 | 按批次号/日期范围/试块编号/操作人筛选查询 |
| 历史记录页 | 详情查看 | 查看完整换算参数、复核计算过程 |

## 3. 核心流程

用户选择角色进入系统 → 录入批次信息和操作人 → 输入实验室配合比参数 → 输入现场砂石含水率、计划方量等 → 系统实时校验并换算 → 确认后保存记录 → 施工员打印配料单 / 技术负责人打印复核表 → 异常时通过历史记录追溯

## 4. 用户界面设计

### 4.1 设计风格
- **主色调**：工业蓝（#1e40af）+ 警示橙（#f97316），体现工程专业感
- **辅助色**：安全绿（#10b981）、警告红（#ef4444）用于校验状态
- **背景色**：浅灰（#f8fafc），卡片白色，数据区浅灰底
- **按钮风格**：方角微圆（4px），实心按钮带轻微阴影，操作按钮组横向排列
- **字体**：思源黑体（Noto Sans SC），数字用等宽字体（JetBrains Mono）便于对比
- **布局风格**：左右分栏卡片布局，左侧输入区，右侧结果区+操作区
- **图标**：线性图标（工程元素：标尺、水滴、水泥袋、立方体试块）

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 配合比换算页 | 顶部信息栏 | 批次号自动生成显示、操作人输入、当前时间、角色切换标签 |
| 配合比换算页 | 左侧输入卡 | 分组折叠面板：实验室配合比、现场参数，每组配单位选择下拉 |
| 配合比换算页 | 右侧结果卡 | 大数字显示各材料用量，校验状态徽章，扣水前后对比表 |
| 配合比换算页 | 底部操作栏 | 重置、保存、打印配料单、打印复核表按钮 |
| 历史记录页 | 查询栏 | 批次号/试块编号搜索、日期范围、操作人下拉 |
| 历史记录页 | 记录列表 | 表格展示批次号、日期、强度等级、方量、操作人、状态标签 |
| 打印配料单 | A4打印页 | 大字号配料表、施工员签字栏、浇筑部位、日期 |
| 打印复核表 | A4打印页 | 完整计算公式、每一步骤数值、技术负责人签字栏 |

### 4.3 响应式
- Desktop-first 设计，主内容区最大宽度 1440px
- 平板端（<1024px）：左右分栏改为上下布局
- 移动端（<640px）：输入分组改为手风琴折叠，表格改为卡片列表
- 打印页面独立样式，@media print 优化

### 4.4 交互细节
- 输入参数时右侧结果实时刷新（防抖 300ms）
- 校验异常时输入框红框+Tooltip提示，按钮禁用
- 保存成功后弹出批次号卡片，可一键复制
- 打印按钮触发前自动调用 window.print()，隐藏操作栏
