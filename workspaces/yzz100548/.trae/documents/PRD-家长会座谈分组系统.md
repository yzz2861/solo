## 1. 产品概述

家长会座谈分组系统是一款面向班主任和年级组长的分组管理工具，解决传统纸质名单难以灵活安排座谈小组的问题。支持拖拽式分组、智能冲突提醒、数据持久化、导出报表及跟进管理，帮助老师高效组织家长会分小组座谈。

## 2. 核心功能

### 2.1 用户角色

| 角色 | 登录方式 | 核心权限 |
|------|----------|----------|
| 班主任 | 本地身份切换 | 录入信息、拖拽分组、导出座谈表、管理跟进 |
| 年级组长 | 本地身份切换 | 查看所有班级跟进情况、安排家访/电话沟通 |

### 2.2 功能模块

1. **信息录入页**：学生信息、家长信息、到场情况、沟通主题、特殊备注、负责老师
2. **分组管理页**：拖拽分组、小组命名、实时提醒、智能提示
3. **导出中心**：导出座谈表、导出跟进清单
4. **跟进管理页**：跟进进度更新、持续跟进家庭列表、家访/电话安排

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 信息录入页 | 学生列表管理 | 添加/编辑/删除学生及家长信息，支持批量导入 |
| 信息录入页 | 老师列表管理 | 添加/编辑负责老师，设置分组上限 |
| 分组管理页 | 未分组池 | 展示所有未分组的家长，支持搜索筛选 |
| 分组管理页 | 分组区域 | 可创建多个小组，支持拖拽加入/移出 |
| 分组管理页 | 智能提醒栏 | 实时显示冲突提醒（老师带组过多、特殊备注冲突、未到家长分组、跟进无负责人） |
| 导出中心 | 座谈表导出 | 导出各小组座谈安排表（CSV/PDF） |
| 导出中心 | 跟进清单导出 | 导出需要跟进的家庭清单 |
| 跟进管理页 | 跟进进度 | 老师更新跟进状态和记录 |
| 跟进管理页 | 年级组长视图 | 查看全年级跟进情况，安排后续家访/电话 |

## 3. 核心流程

用户打开应用 → 选择身份（班主任/年级组长）→ 录入学生与家长信息 → 创建分组并拖拽分配 → 系统实时提醒冲突 → 确认分组后导出座谈表 → 会后更新跟进进度 → 年级组长查看持续跟进家庭并安排后续工作

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：温暖的教育风格，采用柔和的蓝绿色系（#3B82F6 主蓝、#10B981 辅助绿、#F59E0B 提醒橙）
- **按钮风格**：圆角胶囊型按钮，悬停微动效，阴影柔和
- **字体**：标题使用 "Noto Serif SC" 宋体类衬线字体，正文使用 "Noto Sans SC" 无衬线字体，营造专业教育感
- **布局风格**：卡片式布局，分组区域采用可拖拽卡片，留有充足留白
- **图标风格**：线性图标，统一 2px 描边，颜色与主题一致

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 信息录入页 | 学生卡片列表 | 头像、姓名标签、状态徽章、操作按钮 |
| 分组管理页 | 拖拽区域 | 分组列卡片、拖拽占位符、拖拽时半透明效果 |
| 分组管理页 | 提醒面板 | 警告图标、分级颜色（红/橙/黄）、可展开详情 |
| 跟进管理页 | 时间线布局 | 跟进记录时间线、状态标签、进度条 |

### 4.3 响应式

- Desktop-first 设计，主内容区最大宽度 1440px
- 平板端适配：分组区域改为上下布局
- 移动端：单列布局，底部 Tab 导航
- 拖拽操作在移动端改为点击选择+移动的模式

### 4.4 动效设计

- 页面加载：元素淡入+轻微上移，错开 50ms 延迟
- 拖拽：被拖拽元素缩放 1.02 + 阴影加深，目标区域高亮边框
- 提醒出现：从右侧滑入 + 轻微弹跳
- 卡片悬停：上移 2px + 阴影扩散
